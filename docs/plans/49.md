# Issue 49: fewer GitHub calls per tracked issue

Design: [49-poll-cost/design.md](49-poll-cost/design.md). S, N, O and D numbers refer to it.
One PR, branch `issue/49-poll-cost`.

**Seam decision:** A1 touches seam `server-github`; it blocked until Mattias Jonsson accepted
ADR 0023 on 2026-11-12, when he asked for the PRs to be merged.

## 0. Spec at a glance

Branches and open pull requests listed once per repo per tick; title and state from the open
listing; plan re-read only when the branch head moves; comments, first PR look-ups and unlisted
repos on a full tick every 300 s; closed issues settled. `checks` every tick, so *In review* and
*Done* keep their latency.

## Affected parts

| Node | Status | What changes | Seams |
| --- | --- | --- | --- |
| rubato-server | affected | poll reads branches and open PRs per repo, meta from the open listing, plans on head change, comments and closed issues on the full lane | server-github |
