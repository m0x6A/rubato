Task 5 of `docs/plans/v0.md` §5. One instance per team. Signals in, derived picture out.

| Node | Status | What changes | Seams |
| --- | --- | --- | --- |

## Data flow

```mermaid
flowchart LR
  C[rubato-companion] -- CompanionEnvelope --> WS[/ws/companion]
  WS --> EV[(companion_events, session_snapshots, launches, cap_hits)]
  GH[github] -- map, plan files, PRs, checks, comments --> P[poller] --> ROWS[(map_cache, plans, pull_requests, decisions, issue_meta)]
  W[web] -- PinRequest, LaunchRequest --> API[/api/*] --> PINS[(pins)]
  EV & ROWS & PINS --> D[progress::build: derive_progress + findings] --> API
  API -- Overview --> W
  D -- WebEvent::Changed --> WSW[/ws/web] --> W
  API -- LaunchCommand --> WS --> C
```
