# Issue 20: vertical slices

Design: [20-vertical-slices/design.md](20-vertical-slices/design.md). S/N/O/D numbers below refer to it.

## 0. Spec at a glance

- Does: every capability of every deployable lives in one folder; kernel holds leaf infrastructure; a composition root wires; slice imports are shallow and acyclic and a check proves it (S1–S3, S5, S6).
- We'll know it works when: slice checks print their counts and pass; `cargo test --workspace`, `pnpm -r test`, `pnpm e2e` pass; schemas, generated TS, migrations and embeds diff clean; `observability:check` reports 6 rules (S4).
- Must not break: N1–N23 (wire contract, DB schema, routes incl. `/api/health`, SPA fallback, CLI, telemetry names, embeds incl. `team.json`, plan parsing, fixtures and reconnect seq, own-tmux-only, timing and arm orders, e2e, skill vendoring, test ids, hard-coded e2e paths, all ten notify reasons, loop order verbatim, companion with no adopted session, clean shutdown, installed skill files byte-identical).
- Debug at 3 am: O1 `ServerPollSilent` on `rubato_poll_ticks_total` + fail-fast + GitHub timeouts; O2 `rubato.task.exited` + `CompanionSilent`; O3 404 JSON + `warn!` + probe test; O4 panel No data + per-binary e2e list; O5 web-event test; O6 `internal(slice, e)` error line vs ownership table.
