# Task 7: end to end

Task 7 of `docs/plans/v0.md` §5. The whole chain, reproducibly, with no GitHub and no tokens
spent: two connected repos (an auth provider and a consumer) with bare origins, the team's
map, the real `rubato-server` and `rubato-companion`, a Claude Code stand-in that runs the
injected hooks and pushes a plan, an OTLP receiver, and the plan check over what came back.

## Affected parts

| Node | Status | What changes | Seams |
| --- | --- | --- | --- |
| rubato-server | affected | `RUBATO_LOCAL_REPOS`: a GitHub stand-in over local bare repos for branches and plan files | server-github, server-plan-file |
| rubato-companion | quiet | driven as is | companion-server, companion-tmux-ide, companion-claude-code |
| plan-check | affected | run by the e2e over the three pushed plans against the team map | plan-check-plan-file |
| claude-code | quiet | stood in by `e2e/claude-standin.ts`, which executes the hooks from `--settings` exactly as Claude Code would | companion-claude-code |
| github | quiet | stood in by local git; issues, PRs and comments are out of reach locally | server-github |
